# Context Format

Use `context.md` files to capture repository rules in a consistent structure.

## Recommended Sections

1. `Purpose`
2. `Repository Rules`
3. `Workflow`
4. `Testing`
5. `Documentation`
6. `Notes`

## Formatting Rules

- Write in English.
- Keep each rule direct and actionable.
- Prefer short bullets over long paragraphs.
- Put immutable repository policies in `Repository Rules`.
- Put process expectations in `Workflow`.
- Put mandatory validation requirements in `Testing`.
- Put documentation expectations in `Documentation`.

## Example Skeleton

```md
# Context

## Purpose

## Repository Rules

## Workflow

## Testing

## Documentation

## Notes
```
